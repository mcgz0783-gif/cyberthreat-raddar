# 🛡️ CyberThreat Raddar

**CyberThreat Raddar** is a high-fidelity cyber intelligence platform and educational resource designed for security practitioners and enthusiasts. It provides real-time insights, deep-dive articles, and a curated library of cybersecurity literature through a modern, immersive web experience.

## 🚀 Key Features

-   **📖 Immersive Book Reader**: A high-fidelity, responsive A4-style reader simulating physical paper for a distraction-free learning experience.
-   **📰 Live Intelligence Feed**: Real-time news ticker and article hub for the latest security breaches and threat reports.
-   **🎓 Course Directory**: A curated list of top-tier cybersecurity certifications and training paths (TryHackMe, PortSwigger, etc.).
-   **🔍 Security Insights**: In-depth analysis of modern attack vectors like Zero Trust, Malware Analysis, and Social Engineering.
-   **⚡ Performance First**: Built with Vite and React for near-instant load times and smooth transitions.

## 🛠️ Tech Stack

-   **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [Shadcn UI](https://ui.shadcn.com/)
-   **Animations**: Framer Motion / CSS Transitions
-   **AI Integration**: Vertex AI (Gemini) for prompt-driven content management
-   **Hosting**: [Vercel](https://vercel.com/)

## 📦 Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18+)
-   [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-repo/cyberthreat-raddar.git
    cd cyberthreat-raddar
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

### Building for Production

To create a production-ready build:
```bash
npm run build
```
The output will be in the `dist/` directory.

## 🚢 Deployment

The project is optimized for deployment on Vercel. Pushing to the `main` branch will automatically trigger a production deployment.
